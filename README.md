# Methods

## scRNA-seq and snATAC-seq data processing and integration
10x Genomics libraries were aligned and cells called using Cell Ranger ATAC (version 2.1.0) against the mm10 reference genome (version 2020-A-2.0.0). Cell-by-feature count matrices were imported into R (version 4.3.3) and processed using Seurat (version 5.0.3) and Signac (version 1.13.0). RNA counts were log-normalized and scaled. ATAC counts were normalized using term frequency–inverse document frequency (TF-IDF), and gene activity scores were derived by aggregating chromatin accessibility signal over gene promoter regions, providing a chromatin-based proxy for gene expression. RNA and ATAC datasets were integrated using a nearest-neighbor transfer approach implemented in Seurat, enabling transfer of categorical annotations (cluster identity) from the RNA modality to the ATAC modality. The two modalities were then co-embedded into a shared low-dimensional space. Cluster assignments from the RNA data were associated with clusters in the integrated object using a majority-vote approach; clusters excluded during RNA quality control were equivalently excluded from the integrated object.

## Marker gene visualisation
To confirm cluster identity in the ARC and PVH nuclei, expression of canonical neuronal marker genes were visualized across all clusters using both the RNA (log-normalized counts) and ATAC (gene activity score) modalities. Per-cluster mean expression and percentage of expressing cells were computed for each gene and displayed as dot plots. Per-cluster mean expression matrices were Z-score scaled by row and displayed as heatmaps using pheatmap (version 1.0.12). Dotplots were generated with ggplot2 (version 3.5.2).

##  RNA–ATAC concordance analysis
To identify genes with concordant or discordant chromatin and transcriptional dynamics following leptin treatment, per-condition average expression matrices were computed for both RNA (log-normalized counts) and ATAC (gene activity scores) in ARC cluster 0 (AgRP/LepR neurons). Genes consistently upregulated in the ob/ob condition relative to all other conditions were identified in the RNA modality. Pearson correlation coefficients between the RNA and ATAC per-condition average profiles were calculated across all shared genes. Genes were ranked by RNA–ATAC correlation and the top 500 (most concordant) and bottom 500 (least concordant) were selected for heatmap visualization, along with top-50 and bottom-50 subsets for gene-level inspection. Per-condition Z-score matrices were computed separately for RNA and ATAC, and row order was determined by hierarchical clustering of the RNA Z-score matrix, applied consistently to both modalities. Heatmaps were generated using pheatmap (version 1.0.12).

##  SCENIC+ regulon analysis and STAT3 target gene identification
Transcription factor regulon activity was inferred using SCENIC+, which jointly models cis-regulatory element accessibility and gene expression to predict enhancer–gene regulatory links. The resulting STAT3 target gene list was used to subset the RNA expression matrix for subsequent analyses. For the STAT3 target gene expression heatmap scaled RNA expression values for STAT3 target genes were extracted from the single-nucleus RNA-seq data and averaged per cluster per condition. Analysis was restricted to wild-type animals and ARC clusters 0 (AgRP/LepR neurons), 3 (POMC/LepR neurons), and 17 (BNC2/LepR neurons). Genes with zero variance across wild-type cluster averages were excluded. Hierarchical clustering of the remaining genes (cutree k = 8) was performed to define gene expression modules, and the heatmap was rendered with row-scaled Z-score values using pheatmap (version 1.0.12). Gene ontology (GO) over-representation analysis was performed on each gene cluster identified in the STAT3 target heatmap using compareCluster from clusterProfiler (version 4.10.1) with the mouse annotation database org.Mm.eg.db. Both Biological Process (GO:BP) and Molecular Function (GO:MF) ontologies were tested. To assess sensitivity to background gene set choice, enrichment was performed under three background conditions: (1) the whole annotated genome (default org.Mm.eg.db background); (2) Seurat highly variable genes from the RNA component of the ARC object; and (3) all SCENIC+ peak-to-gene target genes across all transcription factors. Enrichment p-values were adjusted using the Benjamini–Hochberg method. Results were visualized as dot plots showing the top 3 and top 5 terms per gene cluster.

##  STAT3 chromatin accessibility footprinting
Tn5 insertion enrichment around STAT3 binding motifs (JASPAR 2022, motif ID MA0144.1) was assessed using the Footprint function in Signac (version 1.13.0), with hexamer insertion bias correction applied using all peaks in the object (in.peaks = FALSE) to ensure sufficient hexamer diversity. Motif positions were obtained from the JASPAR 2022 database via TFBSTools (version 1.40.0) and motifmatchr (version 1.24.0). Footprint analysis was performed on the full merged ARC ATAC object containing all clusters, and per-cluster profiles were extracted at the plotting stage by grouping cells by a combined cluster–condition identifier. Raw Tn5 insertion profiles were smoothed using a sliding window mean of ±7 base pairs and restricted to positions within 100 bp of the motif center. Footprint metaplots were generated for ARC clusters 0 (AgRP/LepR), 3 (POMC/LepR), and 17 (BNC2/LepR) separately, and for all three clusters pooled.

##  Chromatin accessibility at the Otp locus
Per-condition ATAC-seq coverage tracks at the Otp locus (mm10 chr13) were generated using CoveragePlot in Signac (version 1.13.0), restricted to ARC cluster 0 (AgRP/LepR neurons). Fragment files were re-indexed against the subsetted cell barcodes using CreateFragmentObject prior to plotting. Coverage values were normalized by reads per million (RPM) to account for differences in sequencing depth across conditions. To additionally control for differences in cell number per condition, a cell-downsampled version was generated by randomly subsampling each condition to the minimum cell count across conditions prior to coverage computation. STAT3 eRegulon peaks overlapping the Otp locus were annotated as a separate track.

##  STAT3 motif footprinting at Otp-proximal regulatory elements
STAT3 motif footprinting in the context of the Otp locus was restricted to ATAC peaks within 20 kb of the Otp genomic window to focus analysis on the three cis-regulatory elements linked to Otp by SCENIC+. The ATAC object was subset to these proximal peaks prior to motif annotation and footprinting. Footprint analysis was run on a combined object containing cells from ARC clusters 0, 3, and 17 to ensure adequate hexamer coverage for insertion bias correction. Per-cluster profiles were then extracted as described above.
